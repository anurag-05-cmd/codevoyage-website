Drop your character images in this folder using these exact filenames
(the code already looks for them):

  iron-man.png
  spider-man.png
  hulk.png
  thor.png

Recommended: PNG, transparent background, portrait orientation (roughly 700x1300px)
so they fill the diagonal card/hero shapes nicely. JPG works too — just update
the `image` path in app/data/characters.ts to match the extension.
